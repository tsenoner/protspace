# CLI Reference

The full ProtSpace CLI reference now lives on the documentation site:

**https://protspace.app/docs/guide/python-cli**

It covers every command (`prepare`, `embed`, `project`, `annotate`, `stats`, `bundle`, `transfer`, `style`, `serve`) with their complete option tables, the embedder and projection-method catalogues, multi-input behaviour, model-name resolution, intermediate caching, and projection statistics.

Run `protspace <command> -h` for the built-in help of any command.

See also: [Annotation Reference](https://protspace.app/docs/guide/annotations) | [Annotation Styling](https://protspace.app/docs/guide/styling)
